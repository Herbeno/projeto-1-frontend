## Demo online

https://projeto-1-faculdade.netlify.app/

## Páginas

- `index.html` — página inicial
- `projetos.html` — projetos, doação e voluntariado
- `cadastro.html` — formulário com validações nativas (CPF, telefone, CEP)

## Estrutura

```
├── index.html
├── projetos.html
├── cadastro.html
├── css/styles.css
├── js/mascaras.js
└── img/          (PNG, JPG e WebP)
```

## Abrir localmente

Abra `index.html` no navegador ou use uma extensão Live Server.
